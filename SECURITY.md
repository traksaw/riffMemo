# Security Policy

RiffMemo processes on-device audio recordings and syncs data via CloudKit. If you find a security issue — a way to access another user's data, an insecure data-handling gap, or similar — please report it privately rather than opening a public GitHub issue.

**Contact**: [workwithwaskar@gmail.com](mailto:workwithwaskar@gmail.com)

Include what you found, how to reproduce it, and its potential impact. This is a solo-maintained project, so there's no formal SLA, but reports will be acknowledged and addressed as a priority.
